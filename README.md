# ARC AI · коммерческий радар кофейни

Публичный отчёт: https://akaemov.github.io/arc-ai-coffee-demo/

Демо: условная кофейня у Гостиного двора в центре Уфы. Семь реальных конкурентов. Проверка источников: 07.10.2026. Выручка конкурентов и результаты тестов неизвестны.

## Что работает

- Карта зданий и дорог OpenStreetMap с реальными точками; радиусы 300/500/1000 м по прямой, фильтры, карточки и подсчёт выбранных конкурентов.
- Ценовые столбцы и точки «цена / рейтинг». Только капучино 400 мл. Два разнородных среза, без общей медианы; внутри каждой группы n=1. Это не текущая цена рынка.
- Матрица восьми предложений с тремя состояниями и доказательством каждой ячейки.
- Ручная разметка 11 уникальных отзывов двух точек; фильтры периода и тона, тема → примеры → источник. Выборка иллюстративная, не репрезентативная.
- Сценарный калькулятор с синтетическими начальными значениями, без двойного счёта базовой выпечки. Выручка не равна прибыли.
- Пять возможностей, сортировка по предложенным ресурсам/срокам/основаниям и план 30 дней.

Поисковая динамика не получена; временной ряд не придуман. Внутренних данных, секретов, аналитических счётчиков, форм отправки нет. Все вычисления калькулятора локальны в браузере.

## Запуск

GitHub Pages: main, корень репозитория. Для локального запуска используйте обычный статический HTTP-сервер (например `python -m http.server 8000` из каталога проекта). Карта читает map-context.json; при file:// фоновая геометрия может блокироваться браузером. Вендорная Leaflet 1.9.4 сохранена локально, внешний слой тайлов не используется.

Данные: data.json, radar-data.json и radar-data.js. Код интерфейса: index.html, radar.js, radar.css. Неоднозначные форматы и даты остаются явно обозначенными.
