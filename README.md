Объект: условная кофейня у Гостиного двора в Уфе. Проверка открытых источников: 7 октября 2026 года. Реальные конкуренты и организации, гипотетические действия; фактических продаж и результатов тестов нет.

Откройте index.html в браузере: работает без сервера, установки и внешних зависимостей. Фильтры конкурентов, раскрываемые возможности и план на 30 дней работают локально. Источники доступны по внешним ссылкам.

Предлагаемое размещение: отдельный публичный репозиторий akaemov/arc-ai-coffee-demo; GitHub Pages → Deploy from a branch → main → / (root). Публикация требует подтверждения владельца. Готовый комплект не содержит клиентских данных, ключей, аналитических счетчиков или форм отправки.
